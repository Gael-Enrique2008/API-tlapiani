¿Qué es Tlapiani?

Tlapiani es un sistema de monitoreo que combina sensores, una API y una plataforma web para registrar datos del agua y mostrarlos de forma sencilla, visual y accesible.

🧪

Analiza parámetros

Consulta mediciones como pH, turbidez, TDS, temperatura y caudal.

⚠️

Detecta alertas

Identifica valores fuera de rango para apoyar una respuesta más rápida.

📍

Ubica dispositivos

Visualiza el punto donde se encuentra el dispositivo de monitoreo.

Información clara para tomar decisiones

El sistema está pensado para mostrar los datos de manera rápida y entendible, evitando pantallas saturadas o información difícil de interpretar.
