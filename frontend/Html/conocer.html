Conoce el propósito de Tlapiani

Una propuesta tecnológica para monitorear la calidad del agua, visualizar datos y apoyar la detección temprana de riesgos.

¿Por qué nace Tlapiani?

Tlapiani surge como respuesta a la necesidad de contar con información clara sobre el estado del agua. Muchas veces el agua puede parecer limpia, pero sus parámetros físicos y químicos pueden cambiar sin que sea evidente a simple vista.

Por eso, el proyecto propone un sistema que combina sensores, conexión a una API, almacenamiento de datos y una plataforma web para consultar mediciones de manera sencilla.

¿Qué mide el sistema?

El dispositivo está diseñado para registrar parámetros relacionados con la calidad y comportamiento del agua.

🧪

pH

Permite conocer si el agua presenta una condición ácida, neutra o alcalina.

🌫️

Turbidez

Ayuda a identificar partículas suspendidas que pueden afectar la claridad del agua.

💧

TDS

Mide los sólidos disueltos totales presentes en el agua.

🌡️

Temperatura

Registra cambios térmicos que pueden influir en el comportamiento del agua.

🚰

Caudal

Calcula el flujo de agua para observar el movimiento o consumo del líquido.

01

Medición

El dispositivo obtiene datos mediante sensores conectados al ESP32.

02

Envío

Las mediciones se envían a una API en formato JSON para ser procesadas.

03

Visualización

La plataforma web muestra datos, historial, alertas, mapa y reportes.

Un sistema pensado para ser claro

Tlapiani no solo busca recolectar datos, sino presentarlos de forma comprensible para facilitar el análisis y la toma de decisiones.
